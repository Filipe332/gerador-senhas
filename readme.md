## 💡 Sobre o Projeto

Este é um projeto simples de um **Gerador de Senhas Seguras** desenvolvido com **HTML**, **CSS** e **JavaScript puro**. Ele permite que o usuário gere senhas personalizadas, escolhendo o comprimento e os tipos de caracteres a serem incluídos (letras maiúsculas, minúsculas, números e símbolos). O objetivo principal é demonstrar habilidades básicas de desenvolvimento web e manipulação do DOM.

---

## ✨ Funcionalidades

* **Geração Personalizável:** Defina o comprimento da senha (de 4 a 32 caracteres).
* **Seleção de Caracteres:** Escolha entre incluir:
    * Letras Maiúsculas (A-Z)
    * Letras Minúsculas (a-z)
    * Números (0-9)
    * Símbolos (!@#$%)
* **Cópia Rápida:** Botão para copiar a senha gerada para a área de transferência.
* **Validação Simples:** Mensagens de erro para garantir que a senha seja gerada corretamente.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura da página web.
* **CSS3:** Estilização e responsividade da interface.
* **JavaScript (ES6+):** Lógica de geração de senhas e manipulação do DOM.
